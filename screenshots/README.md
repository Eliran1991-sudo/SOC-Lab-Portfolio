# Screenshots

This directory contains images referenced by the portfolio documentation.

| Image | Purpose |
| --- | --- |

Images are historical validation evidence, not a claim of current live status. New images must be reviewed for credentials, personal information, production data, hardware identifiers, and unrelated desktop content before publication.

If a sensitive field is present in a source screenshot, capture a new sanitized version from the lab when possible instead of generating or reconstructing evidence.
