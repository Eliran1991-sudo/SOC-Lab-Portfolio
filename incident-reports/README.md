# Incident Reports

This directory contains evidence-based SOC investigation reports and a reusable template.

- [Incident Report 001](incident-report-001.md): authorized failed Windows logon detection using Security Event ID `4625` and Wazuh rule `60122`.
- [Incident Report Template](incident-report-template.md): structure for future investigations, evidence review, MITRE ATT&CK mapping, classification, and response notes.

Reports must distinguish observed facts from automated mappings, assumptions, and planned work.
